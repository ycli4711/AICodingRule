# 外部系统集成与异步任务方案

适用于外部服务调用、消息、定时任务和异步副作用。先确认参与者职责与业务何时算完成。

## 契约与时序

- 列出触发条件、调用地址或消息主题、生产者与消费者、请求/事件和响应字段的名称、类型与必填性、鉴权、超时及实际适用的错误结果。未取得外部契约时标注待核实。
- 用时序图展示正常流程和关键失败路径，分别标明请求接受、任务完成、状态持久化和外部效果生效；不将任一阶段笼统称为成功。
- 复杂判断或补偿补核心伪代码；状态存储涉及数据库时补关键伪 SQL。

## 可靠性与影响

- 说明重试触发、次数/间隔依据、幂等键、去重、顺序要求、最终失败处理，以及跨系统部分成功的补偿方式；优先复用现有机制。
- 列出生产者、消费者、调度、数据库、配置、监控和既有调用方的影响与预计文件。评估重复执行、丢失、超时后结果未知、限流、并发及敏感数据；把未确定的业务口径列为疑问。
- 验证成功、失败、超时、重试和重复投递等实际存在的路径，分别核对业务状态与外部效果；模拟环境不能证明真实外部系统已生效。
