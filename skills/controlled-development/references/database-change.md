# 数据库结构与数据变更方案

适用于新建或修改表、字段、约束、索引，以及预置、批量更新/删除或历史数据处理。接口按请求单行写入无需机械套用迁移清单；实际查询和写入细节另读 [SQL 与性能检查](sql-review.md)。

## 目标与变更清单

- 说明业务目标、现有结构和可得的数据量证据。逐项列新建或修改的表、字段、约束、索引，以及插入、更新或删除的数据；每项写清用途和目标环境/租户。
- 结构变化给出关键 DDL 或伪 SQL、前后差异、字段类型/可空/默认值、约束与索引依据。数据变化给出来源、选取条件、字段原值与目标值或计算规则、唯一键、预计及允许影响行数。

## 执行顺序与恢复

- 说明应用代码与数据库变更的兼容及执行顺序、事务/批次边界、历史数据回填、重复执行规则、部分成功后的停止和核对方式。
- 明确锁表、空间、停机及新旧版本并行风险；给出可行的回退或备份/补偿依据，不把不可逆数据变化写成可直接回滚。
- 区分编写 SQL 文件、隔离验证和目标库实际执行；核实环境及授权后才执行真实数据操作。

## 影响、疑问与验证

- 列出读写入口、接口字段、报表、任务、权限、现有数据和预计文件。缺少真实结构、数据量或业务口径时列疑问及受影响决定。
- 核对变更前后结构、数据行数与关键查询；成功、失败和重复执行结果按实际风险验证。无法在目标规模或环境验证时明确边界。
